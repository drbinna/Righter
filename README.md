# Righter

One page with direct links into each of my Substack newsletters: the newsletter itself, a new post, the dashboard, posts, stats, subscribers, and settings.

It is a single static file, `index.html`, with no build step.

- Goblin Labs and HackPulse are listed by default.
- Newsletters added, edited, or removed on the page are saved in that browser only (localStorage).
- To change the default list for every browser, edit `DEFAULTS` in `index.html`.

Signing in and out happens on Substack. One Substack sign-in covers every newsletter that account owns or is an admin of.
